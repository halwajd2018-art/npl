# منصة تقارير صندوق التنمية الزراعية – المرحلة الأولى

موقع عربي RTL (FastAPI + SQLite) قابل للتشغيل محلياً على جهاز أو خادم، ويتضمن رفع ملفات PDF/XLSX مباشرة من المتصفح، التقارير الثلاثة، صلاحيات مستخدمين قابلة للإدارة، حذف وإعادة رفع المصادر، وسجل عمليات.

## التشغيل المحلي (Windows / Linux)

1. ثبّت Python 3.11 أو أحدث. على Windows يمكن تشغيل **setup_windows.bat** مرة واحدة ثم **run_windows.bat** في كل مرة لتشغيل الموقع.
2. افتح الطرفية داخل مجلد المشروع:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux / macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. أنشئ حساب المدير لأول مرة (كلمة مرور لا تقل عن 12 حرفاً):
   ```bash
   python create_admin.py
   ```
4. شغّل الموقع:
   ```bash
   uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```
5. افتح **http://127.0.0.1:8000** وسجّل الدخول. لفتح الواجهة من أجهزة الشبكة الداخلية بعد تطبيق ضوابط الأمن: `--host 0.0.0.0`، ثم استخدم عنوان خادم الشبكة. لا تعرضه مباشرة للإنترنت بلا HTTPS.

> التثبيت لا يتضمن أي حساب أو كلمة مرور جاهزة، ولا يحتوي على بيانات المقترضين أو ملفات المصدر المرفوعة.

## التشغيل في خادم إنتاج

تجهيز خاص بشبكة مؤسسية: يُشغّل Docker مع متغير البيئة `SESSION_SECRET` عشوائي قوي، ويوضع خلف Reverse Proxy مع شهادة TLS/HTTPS، وسياسة وصول داخلية، ونسخ احتياطية مشفرة. يتطلب كذلك المراجعة الأمنية والاختبارات التشغيلية وفق سياسات الجهة قبل استخدام بيانات حقيقية.

```bash
export SESSION_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(64))')"
docker compose build
# أنشئ المدير قبل التشغيل (البيانات تتخزن في volume):
docker compose run --rm adf-reports python create_admin.py
docker compose up -d
```

يستمع Docker افتراضياً على `127.0.0.1:8000` في المضيف، ثم يمكن تمريره عبر البروكسي الداخلي مع HTTPS.

## مصادر البيانات

| الرمز | نوع الملف | الحقول الرئيسية | الفترة المرجعية |
|---|---|---|---|
| RPT-01 | تقرير الفروع PDF | المحصل الفعلي، محصل مبادرة الأمن الغذائي، الفرع | سنة-شهر أو تاريخ |
| RPT-01 | مستهدفات Excel | الفرع، المستهدف سداد نقدي ملايين الريالات | سنة |
| RPT-02 | حركات السداد Excel | رقم العقد، المسدد رسوم (متابعة/جدولة)، المسدد الاساسي مع الفائض | سنة-شهر |
| RPT-02 | العقود الإضافية Excel | رقم العقد، نوع القرض | سنة أو سنة-شهر |
| RPT-02 | التصنيف الأساسي Excel | نوع القرض، القطاع | سنة أو سنة-شهر |
| RPT-03 | المحفظة الشهرية Excel | رقم العقد، الرصيد قرض/مقابل مالي، المستحق قرض/مقابل مالي، مبلغ الشطب، السداد الاعتباري نتيجة نقل الدين | سنة-شهر |
| RPT-03 | الجدولة التفصيلية Excel | رقم العقد، المبلغ المجدول | سنة-شهر |

**مهم:** ملف المستهدف السنوي لم يُرفق كـ Excel ضمن المصادر المتاحة عند البناء؛ لذلك يوجد نموذج مستهدفات **مبدئي من الصورة التي قدمها المستخدم** (14 فرعاً لسنة 2026). عند تزويد الموقع بملف Excel المعتمد، اختره في تقرير RPT-01 لتفادي الاعتماد على المستهدفات المبدئية.

## سياسة فصل الفترات ونسخ البيانات

- لكل ملف `UUID` مستقل، بصمة SHA-256، تاريخ رفع UTC، فترة مرجعية، مستخدم رافع، نسخة من الأصل، وملف مشتق للعرض.
- اختيار ملفات التقرير **صريح** ولا يحدث جمع تلقائي للنسخ. اختيار ملفين للمحفظة يتطلب فترة سابقة أقدم. اختيار حركات السداد في RPT-03 يتطلب مطابقة فترة المحفظة الحالية.
- تعديل الفترة المرجعية لا يغير محتوى الملف، ويسجل في سجل العمليات. حذف الملف يحذف الأصل ومشتق البيانات فوراً، ويُبقي بيانات وصفية عن الحذف للتدقيق، ولا يُدرج الملف المحذوف في التقارير.
- لا يوجد استعادة سريعة للمصدر المحذوف داخل الموقع؛ يعاد رفعه من جهاز المستخدم. نظّم النسخ الاحتياطية وفق سياسة مؤسستك.

## قواعد احتساب التقارير

**RPT-01:** `المحصل المحتسب = المحصل الفعلي - محصل الأمن الغذائي` افتراضياً، مع اختيار التحصيل الشامل. `نسبة الإنجاز = المحصل المحتسب / المستهدف السنوي`. محصل المبادرة منفصل أسفل التقرير.

**RPT-02:** `السداد = المسدد رسوم (متابعة/جدولة) + المسدد الاساسي مع الفائض`. لا يُعاد إضافة حركة الفائض. يتم الربط بـرقم العقد **كنص** حتى لا تُحذف الأصفار أو الأحرف في بعض العقود، ثم نوع القرض ← القطاع. تظهر السجلات غير المطابقة منفصلة. تصدير Excel يحفظ التفاصيل الكاملة والمصادر.

**RPT-03:** عقود الشطب من `المبلغ المشطوب الكلي > 0`؛ مقارنة الرصيد قرض، الرصيد مقابل مالي، المستحق قرض، المستحق مقابل مالي بين محفظتين. نقل الدين إذا أصبح الرصيد صفراً وكان مسدد الاعتباري نتيجة نقل الدين غير صفر. الجدولة من تقرير الجدولة التفصيلي (المبلغ المجدول). سجل العقد قد يجمع السداد الجزئي مع الجدولة/النقل؛ كل مبلغ يعرض في مساره المستقل **دون جمع المبلغ المجدول والمنقول على أنه تحصيل نقدي**. لا يعد انخفاض الرصيد سداداً مؤكداً دون حركات سداد متطابقة مع الفترة. الجدولة المرتبطة بملف واحد لا تثبت تاريخ إجراء الجدولة. الحالات غير المؤكدة تعرض للمراجعة.

**قيد محاسبي مهم:** إن كانت حركات السداد المالية لا تعطي تفصيلاً لوقت السداد نسبة لعملية الجدولة أو النقل، سيظهر السداد المثبت خلال الفترة، لكن **لا يمكن إثبات الترتيب الزمني بين السداد والجدولة/النقل** من الملفات الحالية وحدها. يلزم تقرير أحداث الجدولة/النقل مؤرخ إن أريد إثبات التسلسل الزمني لكل عقد.

## إدارة المستخدمين

- اطلاع: عرض التقارير والملفات، وتصدير Excel.
- إضافة: اطلاع + رفع ملفات جديدة.
- تعديل: اطلاع + إضافة + تعديل بيانات الفترات وحذف الملفات.
- مدير: جميع ما سبق + إضافة الحسابات، إيقافها، تغيير الأدوار وكلمات المرور، وسجل التدقيق.
- مخصص: مدير النظام يمكن منح أذونات منفصلة `view,upload,edit,delete,users`.

## تصدير التقارير

- زر Excel ينشئ `.xlsx` بجدول التقرير والمصادر المختارة؛ RPT-02 يتضمن تفاصيل جميع حركات السداد.
- زر «طباعة / حفظ PDF» يستعمل طباعة المتصفح؛ اختر «حفظ بتنسيق PDF» من شاشة الطباعة.

## حدود النطاق الحالي

1. قاعدة البيانات SQLite مناسبة لنسخة محلية أو حجم استخدام محدود؛ التشغيل المؤسسي متعدد الخوادم قد يحتاج PostgreSQL ومخزن ملفات مشترك وعمليات تحليل غير متزامنة.
2. ليست هذه نسخة منشورة على استضافة عامة؛ رفع الملفات المباشر يعمل من المتصفح عند تشغيل الموقع على جهاز/خادم متاح للمستخدم.
3. القراءة متوافقة مع بنية ملفات Excel وPDF التي زُود بها النظام، وقد تتطلب أشكال تقارير PDF مختلفة إضافة قالب استيراد جديد.
4. صلاحية عرض التقارير عامة لكل من لديه `view`؛ الفصل على مستوى الفرع/البيانات الشخصية، إضافة SSO/MFA، وإدارة مفاتيح التشفير مطلوب قبل تشغيل مؤسسي واسع.

## نسخة Android / التابلت (إضافة المرحلة الأولى)

أضيفت إمكانات تثبيت الموقع كتطبيق PWA على Android من Chrome، مع واجهات متجاوبة
وأيقونات التطبيق وmanifest وservice worker يخزن **الأصول العامة فقط** ولا يخزن
التقارير أو بيانات العملاء أو صفحات تسجيل الدخول. تتطلب خاصية تثبيت PWA عنوان
خادم عبر **HTTPS** مع شهادة موثوقة، أو localhost على الجهاز نفسه.

كما يتضمن تسليم نسخة Android مشروعاً أصلياً في `../android-app` (Android Studio):
يوفر WebView آمن، اختيار ملفات PDF/Excel من مدير الملفات، حفظ Excel باستخدام
واجهة الملفات الرسمية في Android وطباعة/حفظ PDF، وإدارة الدخول والصلاحيات عبر
الخادم نفسه. التطبيق متصل بالخادم، ولا يكرر قاعدة بيانات الموقع على الجهاز.

يمكن استخدام `run_for_android_local_network.bat` فقط لاختبار الاتصال على شبكة محلية
خاصة وبيانات تجريبية غير حساسة. للاستخدام الحقيقي يُنشر الموقع على خادم HTTPS
داخلي تحت سياسات أمن المعلومات والحوكمة المعتمدة.
